# Личный сайт на Python / Flask

Простой сайт на Python с крутым оформлением, пустыми панелями и областями для картинки и фона.

## Как запустить

1. Откройте каталог проекта:

```powershell
cd C:\Users\datun\personal_site
```

2. Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

3. Запустите приложение:

```powershell
python app.py
```

4. Откройте в браузере:

```
http://127.0.0.1:5000/
```

## Что здесь есть

- `app.py` — Flask-приложение
- `templates/index.html` — шаблон страницы
- `static/styles.css` — стили оформления

## Что можно менять позже

- `templates/index.html` — текст, заголовок, описание, панельки
- `static/styles.css` — фон, цвета, шрифты
- `app.py` — можно добавить страницу с формой, загрузкой фото и настройкой данных

## Деплой на бесплатный хостинг

Проект готов для загрузки на бесплатные платформы типа Render, Railway, PythonAnywhere или другой сервис для Python.

Чтобы сделать сайт доступным бесплатно из интернета:

1. Загрузите этот каталог на GitHub или другой git-репозиторий.
2. В корне репозитория уже есть `Procfile`, `requirements.txt` и `runtime.txt`.
3. Создайте новый Web Service на Render, выберите GitHub-репозиторий и ветку.
4. В качестве команды сборки используйте `pip install -r requirements.txt`.
5. В качестве команды запуска используйте `gunicorn app:app --bind 0.0.0.0:$PORT`.
6. В Render сайт получит публичный адрес вида `https://<your-service-name>.onrender.com`.

> Важно: бесплатный Render делает сайт доступным из интернета даже когда ваш компьютер выключен.
